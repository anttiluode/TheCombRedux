# Gate 0 — Is the loop causally active and useful?

**Frozen exploratory receipt · 31 October 2026 · commit-tested GitHub Actions.**

This instrument is **not** a competitive AI. The question for Gate 0 was intentionally simpler: does the entire recurrent state actually affect the learned workspace and the comb's decisions, and does that influence improve them?

**Answer: causal path YES, performance advantage NO.** The 16-coordinate reservoir carries a signal the learned readout consumes, but the resulting probabilities are poorly calibrated. A known-model Bayes filter is dramatically better.

## Protocol

- Synthetic binary world and tool inversion, each independently changing at a fixed hazard.
- The agent observes x and noisy y=x XOR world XOR tool; the true world output is x XOR world.
- A tool probe every 17 steps and world probe every 31 steps (tool has priority on coincidences).
- **Train** fixed-random 16D rotating reservoir → learned 4-hypothesis softmax on 340 synthetic episodes × 50 steps with privileged *training labels*; the two comb operator teeth are independently learned.
- **Test** on 12 new random streams, 320 steps per stream, seeds 6102–6104, 6111–6113, and 6220–6225. Training weights stay frozen. The same exact event schedule and probe noise are used in all ablation arms.
- Report probability Brier score for the world output, not just hard accuracy.
- Reference: analytical 4-state Bayesian filter with the correct hazard and observation likelihood; static comb without history.
- No matched GRU/LSTM/Wave-RNN, no learned probe policy, and no different **training** seeds yet.

## Held-out results

| Condition | Accuracy ↑ | Brier ↓ |
|---|---:|---:|
| Intact 16D loop → workspace → comb | **55.86%** | 0.29062 |
| Cut read to workspace, retain stored ring | 50.63% | **0.24998** |
| Erase all 16 coordinates before every input | 52.21% | 0.26569 |
| Mask 14 of 16 coordinates at decoder | 50.70% | 0.27650 |
| Static operator mixture (no memory) | 49.11% | not recorded |
| Exact Bayesian reference | **81.93%** | not recorded |

The intact loop exceeds erased-loop *hard accuracy* by **3.65 percentage points** and exceeds cut-read hard accuracy by **5.23 points**, but has **worse probabilistic Brier score** than both. The proper null for Brier under balanced outcomes is ~0.25. The intact learner has worse Brier than an uninformative half-confidence prediction.

The standard deviation of intact hard accuracy across the 12 held-out streams is **11.24 points**. These differences are exploratory, not significance-tested efficacy claims.

### Deterministic unit/mechanism checks

The Node test run passes:

- Same seed and intervention schedule gives bit-for-bit identical truth, recurrent states, observations, oracle probabilities and decisions.
- Recurrent state read disconnect changes decoded probabilities while preserving stored coordinates.
- Masking coordinates 2–15 changes decoded probabilities: the remaining 14 dimensions are **not merely visualization**.
- Known independent tool and world probes resolve the confounded Bayesian hypotheses.
- Independently trained operators predict copying \`1\` with probability 0.99468 and inverting \`1\` with probability 0.00535 (these are training sanity checks, **not** held-out world decisions).
- The analytics Bayesian reference remains identical between intact and erased-recurrence arms.

The ablation proves the signal enters the decision. It does **not** demonstrate that the signal is helpful, that the loop is a self-model, or that the 16-dimensional geometry beats a simpler filter.

## Interpretation / next gate

The main defect is likely in the **representation and update law**, not the comb teeth: an unguided fixed rotating reservoir followed by one linear classifier does not reliably track two independent hidden-state changes under incomplete observations. It can produce overconfident but wrong beliefs. This is a hypothesis for diagnosis, not established causal attribution.

Gate 1 should learn the recurrent update *and* calibrate its probabilities against 4-state filtering, with the same episode budget, data and probes. Compare:

1. Trained recurrent hidden state or GRU (16D) and matched EMA.
2. Same learned update, but no phase rotation.
3. Trained rotating/gated update.
4. Exact 4-state Bayesian observer (upper reference, not an architecture to claim to beat).
5. Read-path and dimensionality interventions with matched streams.

A better prior should be allowed to succeed! If GRU or a learned four-logit filter wins, preserve that result rather than constructing a topology advantage.
